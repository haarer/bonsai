# Tech Stack

## Android
- Kotlin 2.x
- Jetpack Compose (Material 3)
- CameraX
- Room
- Hilt/Dagger
- Retrofit + Moshi/Gson
- Coil
- DataStore
- WorkManager
- ML Kit Text Recognition or TensorFlow Lite
- Paging 3 (optional)

## Backend (optional)
- FastAPI / Node.js (Express) / Kotlin Ktor
- PostgreSQL / SQLite
- Object storage for images (S3/MinIO)
- Auth (JWT/OAuth)

## Vision Options
- On-device: Google ML Kit, Tesseract4Android, ML Kit Document Scanner
- Remote: OpenAI Vision, Gemini, Claude, Ollama/VLM, custom model
